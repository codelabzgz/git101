# git101

Materiales del taller **Git 101** de CodeLab (Asociacion de Estudiantes de Ingenieria
Informatica, EINA, Universidad de Zaragoza). Cada edicion vive en su carpeta por año.

- `2026/` — edicion actual: muro de snippets con validacion en CI y despliegue automatico
  a GitHub Pages. Instrucciones en `2026/README.md` y guion en `2026/GUION.md`.
- `2025/` — edicion anterior, conservada sin cambios.

## La idea

Durante el taller cada asistente publica un snippet de codigo en la web comun **abriendo un
pull request de verdad**: fork, clone, rama, commit, push y PR. Un workflow de GitHub Actions
valida su fichero y, al hacer merge, la web se regenera y despliega sola. El objetivo es que
el primer PR de muchos asistentes sea en este repo.
